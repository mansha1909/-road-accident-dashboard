# 🚦 Road Accident Dashboard

## 📊 Project Overview
This project analyzes road accident data and predicts casualty severity using machine learning techniques.

## 🎯 Objective
To identify accident patterns and build a predictive model for casualty severity.

## 🤖 Models Used
- Logistic Regression
- Random Forest

## 📈 Accuracy
- Logistic Regression: 0.78
- Random Forest: 0.886

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## 📂 Dataset
Road accident dataset containing casualty and vehicle information.

## 🚀 Features
- Data preprocessing
- Feature encoding
- Model training
- Accuracy comparison
- Visualization

## 📌 Conclusion
Random Forest performed better compared to Logistic Regression in predicting casualty severity.
